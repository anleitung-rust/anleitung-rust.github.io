# Lerne die Programmiersprachenfunktionen kennen

Bisher hast du vor allem Turtle-Befehle kennengelernt: `forward()`, `right()`, `circle_left()`, `pen_up()` und `set_pen_color()`. Das sind wichtige Befehle für die Schildkröte – aber das wird natürlich nie wirklich für richtige Programme verwendet. Im folgenden werden einige Konzepte der Programmiersprache Rust anhand von Turtleprogrammen erläutert. Diese Konzepte finden sich in jedem Rust-Programm. Tatsächlich funktionieren die meisten Programmiersprachen ähnlich und nutzen dieselben grundlegenden Ideen, um Probleme sauber, kürzer und leichter verständlich zu lösen.

In den nächsten Kapiteln wirst du genau diese allgemeinen Bausteine lernen. Die eigentliche Erklärung steckt in den Unterkapiteln – hier nur ein kurzer Überblick:

## 1. Wiederholungen (Schleifen)

Manchmal willst du denselben Befehl oder einige Befehle mehrfach ausführen, zum Beispiel vier Seiten eines Quadrats oder zehn Kreise hintereinander. Dafür benutzt man **Schleifen**.

Wichtige Idee:
- Ein Befehl wird automatisch mehrfach ausgeführt
- Du sparst Zeit und Schreibarbeit
- Der Code wird kürzer und verständlicher

Detaillierte Erklärung: [Wiederholungen (Schleifen)](./070-wiederholungen.md)

## 2. Variablen

Mit Variablen kannst du Werte speichern und später wiederverwenden. Statt eine Zahl immer wieder von Hand einzutippen, legst du sie einmal an und nutzt sie dann immer wieder den Namen statt des Zahlenwertes. So kann man zum Beispiel die Grösse eines Quadrats an nur einer einzigen Stelle festlegen und später auch ändern.

Wichtige Idee:
- Werte werden in einer Variable gespeichert
- Du kannst sie später ändern oder weiterverwenden
- Code wird flexibler und leichter anpassbar

Detaillierte Erklärung: [Variablen](./080-variablen.md)

## 3. Funktionen

Funktionen sind kleine, benannte Codeblöcke, die du immer wieder aufrufen kannst. So kannst du komplexe Aufgaben in überschaubare Teile aufteilen.

Wichtige Idee:
- Wiederverwendbarer Code
- Ein Problem in einzelne Aufgaben zerlegen
- Programme werden besser organisiert

Beispiele:
- `zeichne_quadrat()`
- `zeichne_herz()`
- `zeichne_blume()`

Detaillierte Erklärung: [Funktionen](./090-funktionen.md)

## 4. Weitere Beispiele

Am Ende bringst du alles zusammen: Bewegung, Wiederholungen, Variablen und Funktionen. Dadurch kannst du echte kleine Kunstwerke und Programme bauen.

Detaillierte Erklärung: [Weitere Beispiele](./100-weitere-beispiele.md)

## Warum sind diese Grundlagen so wichtig?

Diese „allgemeinen“ Programmierkonzepte tauchen in fast jeder Sprache auf – nicht nur in Rust, sondern auch in Python, JavaScript, C++ und vielen anderen.

Sie helfen dir:
- Code kürzer zu schreiben
- Fehler leichter zu finden
- Programme besser zu strukturieren
- komplexe Aufgaben verständlich zu lösen
